# Bruteforce to Victory
Bruteforce is somehow the most common and simpler type of hacking. It's job is to try to login using bunch of listed username or passwords inside .txt file. A .txt file alone can go to 80GB+ in size for up to 8 billion passwords for the most comprehensive set, and for the simplier one can consume less MBs. The only cons of this are time-consuming process, and luck.

Sadly, I did not craft one script for bruteforcing, as there are existing ones that are proven working. To try them, first obtain a dictionary .txt file, and then visit their repositories for proper documentation and to obtain a source code.

- [lpb-bruteforce](https://github.com/xiv3r/lpb-bruteforce)
